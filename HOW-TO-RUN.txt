HOSPITAL MANAGEMENT SYSTEM - HOW TO RUN
=======================================

This guide was verified on Windows with PowerShell.

Requirements
------------
- Node.js 18+ (recommended: LTS)
- npm (comes with Node.js)
- Project path: `C:\devops project`

One-time setup
--------------
From project root:

1) Install backend dependencies
   `cd backend`
   `npm install`

2) Install mobile dependencies
   `cd ..\mobile`
   `npm install`

3) Configure backend Firebase environment
   - Create `backend/.env` (or copy from `.env.example`)
   - Set:
     - `GOOGLE_APPLICATION_CREDENTIALS=C:/devops project/backend/firebase.json`
     - `FIREBASE_DATABASE_URL=https://<your-project-id>-default-rtdb.firebaseio.com`
     - `JWT_SECRET=<any long random value>`

4) Ensure Firebase Realtime Database is enabled in your Firebase project
   - Console -> Build -> Realtime Database -> Create database

Run the project (manual, recommended)
-------------------------------------
Open 2 PowerShell terminals.

Terminal 1 - Backend API:
`cd "C:\devops project\backend"`
`npm run seed:firebase`
`npm start`

Expected log:
`HMS API listening on port 3000`
`Firebase Admin: enabled (Realtime DB storage active)`

Terminal 2 - Web app (Expo):
`cd "C:\devops project\mobile"`
`npm run web`

Expected log:
`Waiting on http://localhost:8090`

Open in browser:
`http://localhost:8090`

Quick start script (Windows)
----------------------------
From root:
`cd "C:\devops project"`
`.\start-hms.ps1`

This script starts backend and web app for you.
If Expo asks for another port, choose `n` and free port `8090` first.

Docker option
-------------
From root:
`docker-compose up --build`

Then open:
`http://localhost:8090`

Default ports
-------------
- Backend API: `3000`
- Web app / Expo web: `8090`

Stop the project
----------------
- In each running terminal, press `Ctrl + C`
- If needed, close terminals and restart fresh

Troubleshooting
---------------
1) Port already in use (`3000` or `8090`)
   - Close old Node/Expo processes
   - Or reboot and start again

2) `POST /auth/firebase-session 503 (Service Unavailable)`
   - Backend Firebase Admin is not configured
   - Recheck `backend/.env` values
   - Ensure `backend/firebase.json` exists and is valid

3) `node is not recognized`
   - Install Node.js from [https://nodejs.org](https://nodejs.org)
   - Reopen PowerShell

4) Firebase permission or auth errors
   - Verify service account has access to Realtime Database
   - Verify `FIREBASE_DATABASE_URL` matches the same Firebase project as `firebase.json`
   - In Firebase Auth settings, add `localhost` in authorized domains for web login
